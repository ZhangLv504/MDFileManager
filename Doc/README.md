# MDFileManager (MD 文档管理系统)

一个基于 BS 架构的轻量级 Markdown 文档管理系统。专为个人知识库与项目文档分类设计，支持通过浏览器直接进行 Markdown 文件的增删改查。

## 核心特性

1. **多维分类管理**
   - 支持“项目文档 (Projects)”与“学习知识点 (Knowledge)”等顶级分类。
   - 支持多级子目录结构的树形展示。

2. **同名更新机制**
   - 采用“文件系统映射”模式。在同一个分类路径下，上传或保存同名 `.md` 文件将直接视作版本更新（覆盖），无需复杂的数据库版本控制。
   - 天然支持本地文件系统的直接访问，数据完全掌握在自己手中。

3. **高保真渲染与在线编辑**
   - **格式正确渲染**：前端集成强大的 Markdown 解析引擎，确保打开 MD 文件时，标题、表格、代码块（含高亮）、公式等格式完全正确渲染，拒绝纯文本裸奔。
   - 集成所见即所得的 Markdown 编辑器（如 Vditor 或 Cherry Markdown）。
   - 支持基础的 CRUD（新建、读取、更新、删除）操作。

## 技术栈
- **后端**：Python 3.12.7 + FastAPI (提供 RESTful API，处理文件 IO)
- **前端**：HTML/CSS + **TS/JS (TypeScript / JavaScript)** + Vue3 (独立页面，通过 Ajax/Fetch 与后端交互，负责完整的 MD 格式渲染与交互)
- **存储**：纯本地文件系统 (File System)
